# AlisaGPT

Личный голосовой помощник в навыке Яндекс Алисы и Telegram-бот для настройки и переписки. Python 3.12+, FastAPI, aiogram, SQLite. Это отдельный вызываемый навык: он не заменяет системную Алису, не меняет прошивку Станции и не может сам начинать разговор.

## Быстрый старт

```sh
cd /workspace/AlisaGPT
export UV_CACHE_DIR=/workspace/.cache/uv
uv sync --locked
cp .env.example .env
```

Заполните `.env` локально, не публикуйте его и не присылайте ключи в чат:

| Переменная | Назначение |
| --- | --- |
| `ALISAGPT_API_KEY` | Ключ OpenAI API, отдельный от подписки ChatGPT |
| `TELEGRAM_BOT_TOKEN` | Токен бота, созданного через @BotFather |
| `TELEGRAM_OWNER_ID` | Ваш числовой Telegram user ID; при 0 доступ запрещён всем |
| `ALICE_SKILL_ID` | ID навыка из Яндекс Диалогов |
| `ALICE_WEBHOOK_TOKEN` | Случайный секрет пути webhook, минимум 32 случайных байта |
| `DATABASE_PATH` | Путь SQLite; по умолчанию `data/alisagpt.sqlite3` |
| `DEFAULT_MODEL` | Модель по умолчанию: `gpt-6-luna`; доступность зависит от вашего API-проекта |
| `DAILY_LIMIT` | Число попыток генерации на аккаунт в сутки UTC; по умолчанию 100 |
| `WEB_SEARCH_DAILY_LIMIT` | Максимум поисковых запросов в интернете за сутки UTC; по умолчанию 20 |

Секрет пути можно создать командой `python -c 'import secrets; print(secrets.token_urlsafe(32))'` и сохранить в `.env`. При настройке облачной среды используйте безопасный ввод ключей в настройках. Для API выбран префикс `ALISAGPT_`, так как `OPENAI_` зарезервирован платформой.

Запустите **два процесса** из корня проекта:

```sh
uv run uvicorn app.main:create_app --factory --host 0.0.0.0 --port 8000 --no-access-log
uv run python -m app bot
```

В каждом новом терминале задайте `export UV_CACHE_DIR=/workspace/.cache/uv`, если стандартный кэш uv недоступен для записи.

HTTP access log отключён, чтобы не записывать секретный путь. Также отключите или маскируйте запись URL `/alice/*` на внешнем прокси. Процессы не переживают перезапуск среды. Для постоянной работы нужен сервер с HTTPS и менеджером процессов; облачная среда разработки не является круглосуточным хостингом.

## Подключение Станции

1. Создайте навык в Яндекс Диалогах с backend webhook. Укажите публичный HTTPS URL `https://ВАШ-ДОМЕН/alice/ВАШ-СЕКРЕТ`, полученный через собственный HTTPS reverse proxy к порту 8000. Локальные адреса Станции недоступны.
2. Задайте одинаковые `ALICE_SKILL_ID` и `ALICE_WEBHOOK_TOKEN` в серверной конфигурации. Секретный URL — средство ограничения доступа к webhook; сам `skill_id` не является аутентификацией.
3. Включите тестирование навыка на аккаунте Яндекса, к которому привязана Станция, и задайте имя активации. Проверьте актуальные требования и лимиты в документации Яндекс Диалогов перед публикацией навыка.
4. Напишите Telegram-боту `/start`, затем `/link`. Вызовите навык на Станции и произнесите «Привязать …», диктуя код отдельными цифрами. Код одноразовый и действует 5 минут. Навык требует авторизованный `session.user.user_id`.
5. Задавайте вопросы голосом или текстом в Telegram. История общая (последние 6 пар сообщений). Постоянные факты о пользователе хранятся отдельно. Если ответ готовится дольше 3,5 секунд, навык предложит сказать «продолжи»; повторите через несколько секунд. Навык не может сам заговорить позже без новой реплики пользователя — это ограничение Яндекс Диалогов. Новый вопрос во время ожидания возвращает предыдущий результат, а не запускает новый запрос.

### Постоянная память

В навыке и в обычном сообщении Telegram скажите «запомни [факт]», «что ты помнишь», «забудь номер [номер]» или «забудь всё». В Telegram также доступны `/remember <факт>`, `/memories`, `/forget <номер|all>`. `/reset` очищает только недавний диалог; `/forget all` удаляет постоянные факты. Память хранится в той же SQLite и доступна обеим поверхностям после перезапуска.

После обычных сообщений помощник может автоматически извлечь до двух устойчивых фактов о пользователе дополнительным недорогим запросом к OpenAI. Извлечение идёт в фоне и не задерживает голосовой ответ; при перезапуске незавершённое извлечение может не сохраниться. Это увеличивает число API-запросов и не гарантирует сохранения каждого факта. Пароли, ключи и похожие секреты не сохраняются; для контроля используйте `/memories` и `/forget`. При ответе выбираются до 20 наиболее подходящих фактов, а не вся база памяти.

### Актуальная информация из интернета

Для вопросов о погоде, новостях, курсах, расписаниях и явных просьб «найди в интернете» помощник использует веб-поиск OpenAI. Остальные вопросы отвечаются без поиска. Поиск использует `gpt-6-luna` независимо от модели, выбранной `/model`, и ограничен `WEB_SEARCH_DAILY_LIMIT`; `/usage` показывает расход лимита. Каждый поиск оплачивается отдельно по тарифу OpenAI плюс токены. В Telegram после ответа даются ссылки на источники. На Станции ссылки и перечисление источников не зачитываются. Если город для прогноза неизвестен, помощник спросит его и сохранит в постоянной памяти; факт можно удалить через `/memories` и `/forget`.

Общий обзор новостей готовится в фоне при запуске API и сохраняется в SQLite вместе с найденными источниками. Он объединяет важные события по русскоязычным и международным публикациям и отвечает подробнее обычного короткого ответа. Повторные вопросы в течение часа возвращают готовый обзор сразу. Для погоды повторный запрос того же города использует кэш до 10 минут; при запуске API заранее обновляется прогноз для сохранённых городов. Фоновое обновление тоже расходует поисковый лимит и оплачивается. Если кэш устарел, свежий поиск может занять больше 3,5 секунд.

Поиск иногда занимает больше времени, чем обычный ответ. Если Алиса просит сказать «продолжи», повторите эту команду для получения готового результата. При недоступном веб-поиске помощник не подменяет актуальные данные догадкой.

### Быстрое переключение на помощника и обратно

- Для разговора с AlisaGPT: «Алиса, запусти навык мой ГПТ». После запуска задавайте вопросы обычными фразами. Длинная фраза «Алиса, запусти навык Мой GPT помощник» также остаётся доступной.
- Для одного вопроса без отдельного запуска: «Алиса, спроси у моего ГПТ помощника, [вопрос]». Для этой фразы в Яндекс Диалогах добавлено активационное имя «моего ГПТ помощника».
- Для возврата к обычной Алисе скажите «Алиса, вернись». Навык также завершает сессию по командам «выход», «верни Алису» и «обычная Алиса».

Пока открыт навык, обычные команды Алисы, включая музыку и умный дом, недоступны. После выхода ими снова управляет обычная Алиса. Навык не управляет Яндекс Музыкой напрямую.

## Telegram

Только личный чат владельца. Команды:

- `/model <имя>` — выбрать одну из разрешённых моделей (`gpt-6-luna`, `gpt-4.1-mini`, `gpt-4.1`, `gpt-4.1-nano`). Список можно изменить переменной `ALLOWED_MODELS` как JSON-массив.
- `/prompt <текст>` — инструкция и стиль ответов.
- `/limit <число>` — дневной лимит запросов.
- `/usage` — модель, число попыток и лимит.
- `/reset` — удалить общую историю.
- `/remember <факт>`, `/memories`, `/forget <номер|all>` — управлять постоянной памятью.
- `/link` — создать новый код привязки.
- `/unlink` — отозвать все привязки Станции и неиспользованные коды.

Лимит — не денежный баланс: неуспешные попытки тоже учитываются. Стоимость зависит от модели, истории, ответа и числа поисков. Обычный ответ ограничен 300 токенами, веб-ответ — 400; ввод — 4000 символами. Настройте бюджет и уведомления также в OpenAI; `/usage` не показывает точные списания. Цены в проекте не зафиксированы.

## Проверка и эксплуатация

```sh
uv run pytest -q
curl --fail http://127.0.0.1:8000/healthz
```

Тесты используют подмену OpenAI и не требуют платных запросов. `/healthz` проверяет процесс и наличие конфигурации, а не валидность ключей. Для полной внешней проверки после добавления ключей отправьте вопрос через Telegram и реальную Станцию.

SQLite содержит тексты разговоров и сохранённые факты; ограничьте доступ к `data/` и резервным копиям. Данные отправляются в OpenAI для ответа и извлечения фактов. Не публикуйте базу. `/reset` удаляет локальную историю, а `/forget all` — постоянную память, но они не отзывают уже отправленные запросы провайдеру. `/unlink` блокирует будущие запросы с отвязанных аккаунтов; уже запущенная генерация может завершиться.

Запускайте один worker Uvicorn: ожидающие ответы и короткий кэш повторных webhook находятся в памяти. При перезапуске они теряются; настройки, привязки, история и счётчик сохраняются на диске. Для нагрузки и нескольких серверов потребуется очередь задач и общее хранилище. Навык не поддерживает streaming голоса, управление умным домом или инструменты выполнения команд.

Сеть: `api.openai.com`, `api.telegram.org`, а для установки — PyPI. Настроенные HTTP/HTTPS-прокси и доверенные CA сохраняются; проверка TLS не отключается. Доступность и условия OpenAI зависят от поддерживаемой страны и API-аккаунта.

## Развёртывание на VPS

В каталоге [deploy](deploy/) лежат конфигурации для постоянного запуска на Linux. Они рассчитаны на пользователя `alisagpt`, каталог `/opt/alisagpt` и локальный API на `127.0.0.1:8000`. Перед установкой замените `your-domain.example` в `deploy/Caddyfile.example` на свой домен; временный адрес вида `IP-адрес.sslip.io` тоже подходит. Домен должен указывать на VPS, порты 80 и 443 должны быть открыты.

1. Установите Python 3.12+, `uv`, Git и Caddy из официальных источников. Создайте системного пользователя `alisagpt` без интерактивного входа. Разместите репозиторий в `/opt/alisagpt` и выполните `uv sync --locked` от имени этого пользователя.
2. Скопируйте `.env.example` в `/opt/alisagpt/.env`, заполните значения и дайте доступ к файлу только пользователю `alisagpt` (`chmod 600`). Каталог `data/` также должен принадлежать ему. Секреты вводите непосредственно на сервере; не помещайте их в Git, логи или чат.
3. Скопируйте `deploy/alisagpt-api.service` и `deploy/alisagpt-bot.service` в `/etc/systemd/system/`. Выполните `systemctl daemon-reload` и `systemctl enable --now alisagpt-api alisagpt-bot`.
4. Скопируйте настроенный `deploy/Caddyfile.example` в `/etc/caddy/Caddyfile`, проверьте его через `caddy validate --config /etc/caddy/Caddyfile` и перезагрузите Caddy. HTTPS-сертификат оформляется Caddy автоматически при доступности домена снаружи.
5. Проверьте `https://ВАШ-ДОМЕН/healthz`: оба поля `openai_configured` и `alice_configured` должны быть `true`. Затем укажите в Яндекс Диалогах приватный навык с webhook `https://ВАШ-ДОМЕН/alice/ВАШ-СЕКРЕТ` и тем же `ALICE_SKILL_ID`, что в `.env`.
6. Для привязки отправьте Telegram-боту `/link`, запустите навык на Станции и продиктуйте одноразовый код отдельными цифрами. Код действует 5 минут.

Графика, использованная при создании навыка, находится в [assets](assets/). Файл `.env`, база `data/`, SSH-ключи и токены намеренно не входят в репозиторий. Перед резервным копированием работающей SQLite используйте API backup SQLite, чтобы получить согласованный снимок базы.
